🏡 Real Estate Web Application
--

A fully responsive web application inspired by Realtor.com, designed to provide a seamless experience for both home seekers and listing agents. Buyers can browse, search, filter, and save properties with an intuitive interface, while agents gain powerful tools to manage listings, inquiries, and client engagement. The app ensures accessibility across desktop, tablet, and mobile devices.

📌 Tech Stack
--
* Frontend: HTML, CSS, JavaScript
* Backend: Node.js
* Database: MySQL

✨ Features
--
* Browse property listings with images, descriptions, and prices
* Advanced search and filter options (location, price, bedrooms, bathrooms, property type)
* Detailed property view with images and amenities
* Property list and map view
* Save favorite properties and manage a favorites list
* Save searches and rerun them directly from the saved searches list
* Contact property agents via inquiry forms
* Responsive design optimized for all devices
* Interactive UI with hover effects and modals
* Admin dashboard for managing listings and users
* Notifications and email confirmation system
* Affordability calculator
* Pre-approval application

⌨️ Keyboard Shortcuts
--
* Enter — Submit forms
* Esc — Close modals
* Ctrl + R — Refresh page during testing

🛠️ Development Process
--
1. UI/UX Design:

* Created wireframes and prototypes to ensure a clean, user‑friendly interface.
* Focused on responsive design using media queries, clamp(), and viewport units.

2. Frontend Implementation:
* Built interactive components with JavaScript for handling listing data, user inquiries, favorites, and more.
* Integrated dynamic filtering, search, and pagination functionality.

3. Backend Development:
* Developed Node.js APIs to handle property listings, user accounts, inquiries, among other features.
* Implemented CRUD operations with MySQL for property, user data management, as well as other core entities.
* Implemented third party client side APIs for a live chat system, google sign up, and additional services.

4. Testing & Optimization:
* Conducted cross‑device testing to ensure responsiveness.
* Added keyboard shortcuts and hover effects for improved usability.

--
